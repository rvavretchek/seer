Revisão bibliográfica, verificação de fontes, análise de citações, escrita acadêmica, revisão por pares, verificação de afirmações — competências que qualquer pacote disciplinar do Seer pode compor.

# CORE — Generic Academic-Research Skills (English / en-US)

Literature review, source verification, citation analysis, academic writing, peer review, claim verification — competencies any Seer discipline pack can compose with.

**Status:** complete -- 6 skills live. `literature-review` and `claim-verification` adapted from `vendor/agent-papers-cli/` (Apache-2.0). `source-verification` (CRAAP test, Blakeslee/CSU Chico), `citation-analysis` (Garfield's bibliometrics + the citation-graph tooling already vendored), `academic-writing` (Swales & Feak), and `peer-review` (COPE's ethical guidelines) are original, with no fork equivalent.
