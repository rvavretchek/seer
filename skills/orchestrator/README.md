# Orquestrador

A meta-skill do Seer: decompõe a intenção do pesquisador em disciplinas, métodos e fontes necessárias, e compõe as skills de `skills/core/`, `skills/education/` e `skills/geography/` (e pacotes futuros) para executar. Ver Constituição, Princípio 4 — composição, não coleção.

**Status:** ainda não implementado. Estrutural, a construir a partir do padrão `research-coordinator` de `vendor/agent-papers-cli/` (ver `vendor/PROVENANCE.md`).
